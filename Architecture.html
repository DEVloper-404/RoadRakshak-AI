Stage 1–3 · Input & Preprocessing
01 · Input
Camera Feed Input
Static images or live video frame streams from CCTV & ANPR cameras. Supports RTSP streams and image uploads.
→ RTSP · JPEG · H.264
02 · Pre-filter
Quality Assessment
Scores each frame for brightness, blur severity, rain-streak density, and saturation before committing compute resources.
→ Laplacian variance · Histogram analysis
03 · Enhance
Adaptive Preprocessing
CLAHE for low-light enhancement · Dark-channel-prior dehazing for fog/rain · Wiener deconvolution for motion blur.
→ OpenCV · Albumentations
Stage 4–6 · Detection & Classification
04 · Detect
YOLOv8 Detection
Fine-tuned on Indian traffic imagery. Localizes persons, vehicles, two-wheelers, helmets, and heads in a single forward pass.
→ YOLOv8s · COCO pretrain · IDD fine-tune
05 · Classify
Violation Classifier
Two-stage: crops detected regions, then runs focused classifier. Assigns violation type, confidence score, and severity rank.
→ Helmet · Triple riding · Red-light · Seatbelt
06 · Identify
Plate Detection + OCR
Dedicated YOLOv8 plate-head detects plate region. EasyOCR/PaddleOCR extracts registration text with confidence gating.
→ EasyOCR · PaddleOCR · IND plate format

Key Innovations · Beyond Standard Detection
Repeat Offender Memory
Plates cross-referenced against violation history. Habitual offenders flagged automatically.
Risk-Ranked Priority
Violation severity scores surface the most dangerous cases first for officers.
Instant Officer Ping
High-severity violations push real-time SMS/WhatsApp alerts via Twilio to nearest officer.
Explainable Flags
Grad-CAM overlays show exactly which region triggered each violation detection.
Fail-safe Evidence
Low-confidence reads routed to manual review — never silently logged as confirmed.
Built for the Dark
Trained on synthetic night, rain, fog & blur — robustness is a design goal, not an afterthought.
